# HR Data Portfolio

Two workforce analytics projects for the Australian higher-education sector. Each is
self-contained, with its own README, data, code, tests and outputs.

| Project | Data | What it shows |
|---|---|---|
| [`workforce-analytics/`](workforce-analytics/) | Synthetic HR extract for a fictional university | End-to-end workforce reporting: data cleaning with an audit log, headcount, turnover, pay gap and representation metrics, a resignation model, an Excel report and an executive briefing. |
| [`uni-gender-equity-benchmark/`](uni-gender-equity-benchmark/) | Real public data from the Workplace Gender Equality Agency (data.gov.au, CC BY 3.0 AU) | Benchmarking one university against 36 others on women in leadership, with an Excel workbook that re-benchmarks any university from a drop-down. |

Both projects deliver an Excel workbook built from live formulas, a PowerPoint briefing, and
automated tests that reconcile the workbook against the Python results.
